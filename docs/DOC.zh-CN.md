# HiPerCalc — 中文超高精度命令行计算器

一个跑在命令行里的计算器：**80 位内部精度**、结果**能做精确符号推导就绝不给近似值**、中文界面、三语可切。
本文是**功能手册**——只讲"能算什么、怎么输入、会得到什么"，不涉及任何实现细节。

## 1. 启动与退出

直接运行程序即进入**交互模式**：输入算式按回车看结果，`/` 开头的指令用于设置，输入 `/exit` 退出。

也可以**非交互**使用，适合写脚本或批量验算：

| 用法 | 说明 |
|---|---|
| `hipercalc -e "表达式"` | 只算这一条，只打印结果（无提示符、无耗时行）|
| `hipercalc -f 脚本文件` | 逐行执行文件内容 |
| `hipercalc --stdin` | 从标准输入逐行读取 |
| `hipercalc --lang zh-TW` | 强制界面语言（简体 / 繁体 / 英文）|
| `hipercalc -q` | 不显示"用时"一行 |

退出码：正常 0、计算错误 1、启动参数错误 2。

## 2. 输入的基本规则

- **运算符**：`+` `-` `*` `/` `^`（乘方）、`!`（阶乘）、`|x|`（绝对值）。
- **省略乘号**：`2x`、`3(4+5)`、`xy` 都按乘法理解（`xy` 是 x 乘 y，不是变量名）。
- **函数**：`sin(x)`、`sqrt(2)`、`log(2, 8)`（第一个参数是底数）。
- **大小写**：函数名不分大小写；**变量名**是单个小写字母。
- **中文输入法**：全角字符会自动转成半角，不必手动切换。
- 算式后面的中文说明会被忽略，只认算式部分。

## 3. 结果的两种显示：精确值与近似值

这是本计算器最要紧的一点：

- **`=`** 表示结果是**精确**的。例如 `1/3 + 1/6` 给 `= 1 / 2`，`sqrt(8)` 给 `= 2*sqrt(2)`，`sin(pi/6)` 给 `= 1 / 2`。
- **`≈`** 表示只能给出**近似值**（如 `sin(1)`、`ln(2)`），按当前设定的有效数字显示。

能用精确形式表达的，程序绝不退化成小数；确实做不到精确时才给近似值。

## 4. 基础运算

四则运算、乘方、开方之外还支持：

- **整除与取模**：`idiv(17, 5)` = 3、`mod(17, 5)` = 2。
- **组合与数论**：`nCr(5,2)`、`nPr(5,2)`、`gcd(12,18)`、`lcm(4,6)`、`isprime(97)`、`nextprime(100)`、`prevprime(100)`。
- **取整与符号**：`abs(-3)`、`sign(-5)`、`floor(2.7)`、`ceil(2.1)`、`round(2.5)`。

大数、高次幂、大阶乘都能算，并带**规模保护**：普通模式遇到过大的输入会明确提示而不是卡死；确实需要死算时用 `/mode deep`（见第 22 节）。

## 5. 常数与精度

内置常数：`pi`、`e`、`tau`（2π）、`phi`（黄金比）、`i`（虚数单位）、`ans`（上一次结果）。

- **内部精度**默认 80 位，可用 `/mode prec 200` 提高。
- **显示位数**默认 20 位有效数字，可用 `/mode digits 30` 调整。
- 科学计数法写作 `2.5e-8`；结果是否允许科学计数法用 `/mode sci on|off` 控制。
- 整数是否加千分位用 `/mode group on|off` 控制（默认关）。

## 6. 函数一览

- **三角**：`sin` `cos` `tan` `cot` `sec` `csc`；反三角 `arcsin` `arccos` `arctan` `arccot` 等（也可写作 `asin` `acos` `atan`，两种写法等价）。
- **角度制 / 弧度制**：`/mode deg` 或 `/mode rad` 切换。
- **特殊角的精确值**：`sin(pi/6)`、`cos(60°)`、`tan(pi/4)` 会直接给精确结果，而不是小数。
- **对数与指数**：`ln`、`log(底数, 真数)`、`log2`、`log10`、`exp`、`sqrt`、`cbrt`、`nroot(x, n)`。
- **双曲与反双曲**：`sinh` `cosh` `tanh` 及 `asinh` `acosh` `atanh` 等。

## 7. 特殊函数

| 函数 | 说明 |
|---|---|
| `gamma(x)` | 伽马函数。正整数给精确阶乘；**正半整数给精确的 √π 形式**（`gamma(1/2)` = `sqrt(pi)`）|
| `erf(x)` / `erfc(x)` | 误差函数与补误差函数 |
| `zeta(s)` | 黎曼 ζ 函数。整数点给精确值（如 `zeta(2)` 含 π²），其余给高精度近似 |
| `cbrt(x)` / `nroot(x, n)` | 立方根 / n 次根 |

## 8. 数制与位运算

- **二/八/十六进制字面量**：`0b1010`、`0o17`、`0xFF`。
- **位运算**：`and(a,b)` `or(a,b)` `xor(a,b)` `not(a)` `shl(a,n)` `shr(a,n)`。
- **按指定进制显示结果**：`/base hex`（或 `dec` / `oct` / `bin`），只影响整数结果的显示。
- **进制转换**：`bin(10)`、`hex(255)` 等可把数字转成对应进制的写法。

## 9. 统计

数据点既可以写成**列表**，也可以写成**表达式 + 范围**（让自变量跑一遍）：

| 功能 | 例子 |
|---|---|
| 平均值 | `mean([1,2,3,4])` = `5 / 2`、`mean(k, k, 1, 4)` = `5 / 2` |
| 总体方差 / 标准差 | `var([2,4,4,4,5,5,7,9])`、`stddev(...)`（除以 n）|
| 样本方差 / 标准差 | `var_s(...)`、`stddev_s(...)`（除以 n−1）|
| 中位数 | `median([3,1,2])` = 2、`median([1,2,3,4])` = `5 / 2` |
| 百分位 | `percentile(25, [1,2,3,4,5])` = 2（线性插值）|
| 相关系数 | `corr([1,2,3],[2,4,6])` = 1（完全线性相关）|

列表用方括号写：`[1,2,3]`；范围写法里第二个参数是**自变量**，后两个是起止值。

| `NA` | `AVOGADRO` | 阿伏伽德罗常量 |
| `QE` | `ELEMENTARY_CHARGE` | 元电荷 |
| `ME` / `MP` / `MN` | `ELECTRON_MASS` / `PROTON_MASS` / `NEUTRON_MASS` | 电子 / 质子 / 中子质量 |
| `RGAS` | `GAS_CONST` | 摩尔气体常量 |

## 11. 单位与量纲

单位可以直接跟在数字后面，程序会**记住单位**并让它参与运算——也就是真正的量纲计算。

| 输入 | 结果 | 说明 |
|---|---|---|
| `3 km` | `3000 m` | 自动折成国际单位制 |
| `3 km + 500 meter` | `3500 m` | 同量纲相加 |
| `3 km / 2 second` | `1500 m/s` | 量纲自动演化 |
| `2 second * 3 km` | `6000 m*s` | 乘除让量纲指数相加 / 相减 |
| `(2 km)^2` | `4000000 m^2` | 幂让量纲指数乘 n |
| `1 km / 1 mile` | `≈ 0.621371` | 同量纲相除得纯数 |
| `90 kph + 10 kph` | `≈ 27.78 m/s` | 换算后再相加 |

**指数属于单位**：`3 km^2` 表示"3 平方公里"= 3 000 000 m²（不是 `(3 km)²`）。

**量纲不同会直接报错**，这正是量纲计算的价值所在：

- `3 km + 2 second` → 报"量纲不同，不能相加减"
- `3 km + 2` → 报"带量纲的值不能与无量纲的数相加减"（乘除则可以）
- `sin(3 km)` → 报"函数不接受带量纲的值"

**可用单位**：米（`m` / `meter`）、千米、厘米、毫米、微米、纳米、英寸、英尺、码、英里、海里；秒（`s` / `second`）、毫秒、分钟、小时、天、周；克、千克、毫克、吨、磅、盎司；升、毫升、公顷、英亩；`kph`、`mph`、节；卡、电子伏；巴、大气压。**大小写不敏感**（`KM`、`Km`、`km` 等价）。

**单位只在数字后面才算单位**：`3 m` 是 3 米，而单独的 `m` 仍然是变量——所以单字母单位不会与变量冲突。

## 12. 复数

虚数单位写作 `i`，直接用：`(2+3i)*(1-i)` = `5 + i`、`i^2` = `-1`、`sqrt(-4)` = `2i`。

- **分量操作**：`re(2+3i)`、`im(2+3i)`、`conj(2-3i)`、`arg(1+i)`、`abs(3+4i)`。
- **任意次幂都支持**（取主值）：`i^i` ≈ 0.2078795764（= e^(−π/2)）、`2^i`、`i^(1/2)` = (1+i)/√2。
- **负实数的开方与对数自动进复数域**：`sqrt(-4)` = `2i`、`ln(-1)` ≈ 3.14159i。
- **整数次幂仍给精确结果**（如 `(1+i)^2` = `2i`），只有非整数次幂才落到近似值。

## 13. 矩阵与线性代数

矩阵用方括号写，而且**和普通数值一样是一个值**——可以存进变量、也可以被 `ans` 记住。

| 功能 | 例子 | 结果 |
|---|---|---|
| 构造 | `[[1,2],[3,4]]` | `[[1, 2], [3, 4]]` |
| 行向量 | `[1,2,3]` | 一行三列 |
| 行列式 | `det([[1,2],[3,4]])` | `-2` |
| 迹 | `trace([[1,2],[3,4]])` | `5` |
| 秩 | `rank([[1,2],[2,4]])` | `1` |
| 转置 | `transpose([[1,2],[3,4]])` | `[[1, 3], [2, 4]]` |
| 逆 | `inv([[1,2],[3,4]])` | `[[-2, 1], [3/2, -1/2]]` |
| 乘法 | `[[1,2],[3,4]]*[[1],[1]]` | `[[3], [7]]` |
| 数乘 | `[[1,2],[3,4]]*2` | `[[2, 4], [6, 8]]` |
| 同形加减 | `[[1,2],[3,4]]+[[1,1],[1,1]]` | `[[2, 3], [4, 5]]` |
| 整数次幂 | `[[1,2],[3,4]]^2` | `[[7, 10], [15, 22]]`（0 次给单位阵）|
| 解线性方程组 | `linsolve([[1,1],[1,-1]],[3,1])` | `[[2], [1]]` |
| 特征值 | `eigen([[1,2],[2,1]])` | `[[-1, 3]]` |

要点：

- **元素可以是精确值或复数**，所以整数矩阵的行列式给精确值，复数特征值也能给出（`eigen([[0,-1],[1,0]])` = `[[i, -i]]`）。
- **特征值目前支持 2×2 与 3×3**，更大的会明确告知。
- 矩阵存进变量后可以继续参与运算：先 `/let A = [[1,2],[3,4]]`，再 `det(A)`。

## 14. 方程

把等式写进去就会求解：`x^2-4=0` 给 `x = 2, x = -2`。

- **精确优先**：能用精确形式表达就用精确形式；判别式不是完全平方时给高精度近似根。
- **给出全部根**：高次方程会给出全部实根与复根。
- **有理方程**（含分式的）会先通分再解，所以 `(x-3)/(x-5)=x` 会给出 `x = 3∓√6` 的**两个根**。
- **无穷多解**用通式表示（如带周期的三角方程）。
- 无解时明确说"无解"，不会给错答案。

## 15. 方程组

用逗号分隔多个等式：`x+y=5, 2x-y=1`。

- **线性方程组**用消元法求解，结果按显示模式输出。
- **非线性方程组**用数值方法求解。

## 16. 不等式与不等式组

不等号支持 `<` `>` `<=` `>=` `=<` `=>` `!=`（以及 `≤` `≥` `≠`）。**大于等于两种写法都收，不等用 `!=`**。

| 输入 | 结果 |
|---|---|
| `x^2>4` | `x ∈ (-∞, -2) ∪ (2, ∞)` |
| `x^2<=4` | `x ∈ [-2, 2]` |
| `(x-1)*(x-2)*(x-3)>0` | `x ∈ (1, 2) ∪ (3, ∞)` |
| `x^2!=4` | `x ∈ (-∞, -2) ∪ (-2, 2) ∪ (2, ∞)`（挖掉 ±2）|
| `x>=1, x=<3` | `x ∈ [1, 3]`（**不等式组求交集**）|
| `x>1, x<3, x!=2` | `x ∈ (1, 2) ∪ (2, 3)` |
| `x^2+1>0` | `x ∈ (-∞, ∞)`（恒成立）|
| `x^2+1<0` | `∅` |

解集统一用**区间记号**表示，端点开闭一目了然；不等式组用逗号分隔，结果是各条解集的交集。

> 目前支持**多项式**不等式；含分式或根式的不等式会明确报错，不会给错答案。

## 17. 因式分解与素因数分解

- **多项式因式分解**：`factor(x^2-1)` 给出因子；`fac(...)` 是同义写法。
- **素因数分解**：`primefac(360)` 给 `360 = 2^3 * 3^2 * 5`；负数也能分解（`-12 = -2^2 * 3`）。

## 18. 多项式函数拟合

给出若干坐标，程序反推出穿过它们的多项式：

- 两点 → 一次函数，三点 → 二次函数，以此类推。
- 坐标中带 `P` 的点表示**顶点**，会按顶点条件参与拟合。
- 也可以给出带未知参数的模板；欠定时会输出参数之间的关系。

## 19. 三角形求解

`triangle(a=3 b=4 c=5)` 或 `triangle(a=3, b=4, c=5)`（括号内用空格或逗号分隔）会一次算出**其余全部量**：三边、三角、三条高、面积、周长、外接圆半径、内切圆半径。

**记号规则**：小写字母是边，大写字母是角，`h` + 大写字母是这条边上的高（`hA` 是 `a` 边上的高）。`a` 与 `A` 是同一个顶点，所以 `triangle(a=3 b=4 c=5)`、`triangle(A=30 b=5 C=60)`、`triangle(hA=4 a=3 b=4)` 都合法。

**字母不限于 a/b/c**：`triangle(x=3 y=4 z=5)` 与 `triangle(a=3 b=4 c=5)` 完全等价，输出标签跟着你写的字母走（`X ≈ 36.87…`、`hZ = 12/5`）。希腊字母同样可用，例如 `triangle(α=3 β=4 γ=5)`。

- 顶点按**首次出现顺序**排定，所以输出顺序和你写的顺序一致。
- 只写了两个字母时会自动补第三个：`triangle(x=1 y=2)` 的第三个顶点是 `z`，`triangle(p=1 q=2)` 的第三个顶点是 `r`。
- 一次最多出现三个不同字母，写第四个会报错。

支持 SSS / SAS / ASA / AAS / SSA 各种已知条件；能解析求解的走解析解，其余数值兜底。SSA 情形可能有两解，程序会把两种都给出来；角度单位跟随当前 `/mode deg|rad`。

## 20. 高等数学

| 功能 | 写法 | 说明 |
|---|---|---|
| 求导 | `diff(f, x)` | 支持高阶：`diff(f, x, 2)` |
| 极限 | `lim(f, x, a)` | 可求单侧极限与无穷远极限 |
| 积分 | `int(f, x)` / `int(f, x, a, b)` | 不定积分与定积分 |
| 泰勒展开 | `taylor(f, x, a, n)` | 在 x=a 处展开到 n 阶 |
| 求和 | `sum(f, k, a, b)` | Σ |
| 求积 | `prod(f, k, a, b)` | Π |

这些函数在解析期就展开成等价的普通表达式，因此可以和其它运算自由组合（如 `diff(x^2,x)+1`）。带变量的结果（如 `diff(x^3,x)` = `3*x^2`）会作为符号结果直接显示。

## 21. 变量存储

- `/let A = 3.5` 存变量；**变量名必须全大写**，之后在算式中直接用 `A`。
- 变量会**自动持久化**：重启程序后仍然在。
- 变量可以是精确值、复数、矩阵、带量纲的值——存什么都能存。
- `ans` 保存上一次的结果，随时可用。

## 22. 指令大全

指令以 `/` 开头；输入 `/help` 可查看全部指令。常用指令：

**计算模式**

| 指令 | 作用 |
|---|---|
| `/mode fast` | 默认。遇到超大输入给提示，而不是死算 |
| `/mode deep` | 死算模式：取消规模上限、输出完整精度 |
| `/mode prec N` | 设置内部精度（默认 80 位）|
| `/mode digits N` | 设置显示有效数字（默认 20 位）|
| `/mode sci on\|off` | 结果是否允许科学计数法 |
| `/mode group on\|off` | 整数是否加千分位 |
| `/mode deg` / `rad` | 角度制 / 弧度制 |
| `/mode mathio` / `lineio` | 符号显示 / 小数显示 |
| `/mode latex` | 结果以 LaTeX 源码形式输出 |

**显示与外观**

| 指令 | 作用 |
|---|---|
| `/base dec\|hex\|oct\|bin` | 整数结果按该进制显示 |
| `/unit km` / `/unit off` | 让**无量纲**结果按指定单位显示 |
| `/lang zh-CN\|zh-TW\|en` | 切换界面语言 |
| `/set 颜色项 颜色` | 自定义各类输出颜色 |
| `/let NAME = 值` | 存变量 |

## 23. 显示格式与开关

- **MathIO（默认）**：尽量用符号形式，如 `1 / 2`、`(1 / 2)*sqrt(2)`、`pi`。
- **LineIO**：一律小数，按设定的有效数字显示。
- **LaTeX**：`/mode latex` 后，结果以可直接粘贴进论文的 LaTeX 源码给出。
- **进制**：`/base` 只影响整数结果的显示，不改变数值本身。
- **单位显示**：`/unit` 只影响无量纲结果的显示；带量纲的结果**自带单位**，不受它影响。

以上开关都只改变"怎么显示"，不改变计算结果。

## 24. 界面语言与配色

- **三语界面**：简体中文、繁體中文、English。首次启动自动跟随系统语言，也可用 `/lang` 手动切换。
- **配色**：`/set` 可分别设置结果、错误、提示、变量等各类文字的颜色，设置会被记住。

## 25. 输入体验

- **Tab 补全**：函数名、变量名、`/` 指令都能补全；补成函数时会自动补出括号并把光标放进中间。
- **括号自动配对**：输入 `(` 会自动补出 `)` 并把光标放进中间；再输入 `)` 会**越过**已有的右括号，不会重复。
- **括号配对高亮**：光标旁的括号成对高亮，不配对的括号会标红。
- **参数提示**：光标停在函数括号里时，提示区会显示该函数的参数形式。
- **按键**：全角字符自动转半角；`Ctrl+L` 清屏、`Ctrl+R` 反向搜索历史；**空闲时 `Ctrl+C` 退出程序，计算中按 `Ctrl+C` 可中断当前运算**。

## 26. 已知边界

如实列出目前不支持或受限之处：

- **量纲**：结果统一用国际单位制基本单位表示，暂不自动合成"平方公里""千米每小时"这类复合写法；也不支持前缀与单位组合（可写 `km`、`mm`，不能拆成 `k` + `m`）。
- **不等式**：只支持多项式不等式。
- **矩阵**：特征值支持 2×2 与 3×3；不提供矩阵除法（可用 `inv(A)*B`）。
- **统计**：数据点需要在解析期可求值（用 `/let` 变量没问题）。
- **特殊函数**：`gamma` 目前支持正整数与正半整数。
- **计算中中断**：Windows 与 Linux / macOS 都支持，只在"计算进行中"生效。
